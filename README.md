My Book App 📚

Hi! This is an app for keeping track of books as a coding challenge for XTIVIA.

What I used here:

*   React (for the main app parts)
*   TypeScript (to help with code and avoid mistakes)
*   Tailwind CSS (for making it look nice)
*   Flowbite (for some ready-to-use UI things like forms and buttons)
*   Open Library API (this is where I get the book information)

How to run it on your computer:

1.  First, you need Node.js and npm.
2.  Download all the project files.
3.  Open your computer's terminal (like cmd or PowerShell).
4.  Go into the project folder using the `cd` command. For example: `cd path/to/your-project-directory`
5.  Type `npm install` and press Enter. This will download things the project needs.
6.  Then type `npm start` and press Enter.
    This should open the app in your web browser at [http://localhost:3000](http://localhost:3000).
